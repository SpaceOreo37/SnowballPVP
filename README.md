# Snowball Fight Game

A multiplayer web-based snowball fight game built with Three.js, Cannon.js, and Socket.IO.

## Features

- First-person perspective
- Real-time multiplayer gameplay
- Physics-based snowball throwing
- Player health system with respawning
- Snowy environment

## Prerequisites

- Node.js (v14 or higher)
- npm (Node Package Manager)

## Installation

1. Clone the repository
2. Install dependencies:
```bash
npm install
```

## Running the Game

1. Start the server:
```bash
npm start
```

2. Open your web browser and navigate to `http://localhost:3000`

## How to Play

- Use **WASD** keys to move
- Use the **mouse** to look around
- **Click** to throw snowballs
- Hit other players 3 times to eliminate them
- Eliminated players will respawn after 3 seconds

## Controls

- W: Move forward
- A: Move left
- S: Move backward
- D: Move right
- Mouse movement: Look around
- Left click: Throw snowball

## Technical Details

- Built with Three.js for 3D graphics
- Cannon.js for physics simulation
- Socket.IO for real-time multiplayer functionality
- Express.js for the web server

## Development

To run the game in development mode with auto-restart:
```bash
npm run dev
```
